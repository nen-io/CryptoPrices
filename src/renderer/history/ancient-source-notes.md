# Ancient and early money: source notes

Verified 17 September 2026. Twenty distinct museum objects: nineteen Cleveland Museum of Art records and one Metropolitan Museum of Art record. Each selected image has item-level public-domain/CC0 evidence; all JPEG files are direct, unmodified museum web renditions. Separate obverse/reverse records of the same accession were excluded. All twenty images were visually inspected for subject relevance, legibility and duplication.

Cleveland policy: https://www.clevelandart.org/open-access — designated public-domain images and collection data are CC0. Met policy: https://www.metmuseum.org/policies/image-resources — public-domain Open Access images are supplied under CC0. CC0 reference: https://creativecommons.org/publicdomain/zero/1.0/. No museum endorsement is implied.

Discovery: https://openaccess-api.clevelandart.org/api/artworks/?q=coin&has_image=1&cc0=1&limit=1000 and https://collectionapi.metmuseum.org/public/collection/v1/search?hasImages=true&q=knife%20money. Fields were verified in those official collection responses. Per-object API URLs below permit re-verification.

Dating: display dates preserve museum catalogue wording. sortYear is an editorial ordering key within a catalogued interval, not a claimed exact minting year; negative values mean BCE. Creator fields preserve cultural/mint attribution and explicitly mark unnamed makers. Captions paraphrase museum descriptions or, where no description exists, remain limited to catalogued object facts. Broad or potentially disputed museum attributions have not been silently narrowed.
